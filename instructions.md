# Badge hunt: official green vocabulary

> **How you'll submit this lab**
>
> This repo is your lab. Fork it, do the work described below in your fork, then open a pull
> request back into this repository. An AI reviewer will check your PR against `rubric.md` and
> leave feedback directly on the PR. See `README.md` for the full workflow.

This lab is **optional**. If you want **official Green Software Foundation–aligned vocabulary**, a structured self-paced path, and a **digital credential** from the Linux Foundation after you pass their exam, this is for you. It reinforces what you read in [Green Software & Sustainable AI](../content/01_green-tech-fundamentals.md); it does **not** replace the required [Green Tech Assessment](01_lab_green-tech-assessment.md).

The course is **free and self-paced** on the Linux Foundation training portal. **Credential details, exam rules, and any fees can change**, always check the current course page before you rely on it for your CV or client work.

- **Training portal (enroll / take the course):** [Green Software for Practitioners (LFC131)](https://trainingportal.linuxfoundation.org/courses/green-software-for-practitioners-lfc131)

## Submission hygiene

- **Filenames:** Use clear names for any evidence files you submit (screenshots, PDFs, links list).
- **Scope:** Your **GitHub** repository must contain **only** artifacts tied to this optional lab (course progress or credential evidence)—not unrelated work.
- **README:** Include a `README.md` that maps what each file proves.

**GitHub only:** Submit the URL to a **GitHub repository** with evidence committed (for example screenshots or completion PDFs)—**not** a standalone cloud link as the only artifact.
