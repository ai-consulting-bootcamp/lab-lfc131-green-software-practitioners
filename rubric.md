# Grading rubric: Green Software for Practitioners (LFC131) — optional

**Source lab:** [`instructions.md`](./instructions.md)

This lab points students to the Linux Foundation **LFC131** course. Grading is optional and cohort-dependent (some programs give completion credit, others treat it as self-study only).
